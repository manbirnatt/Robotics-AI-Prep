# Robotics AI Prep

An offline study app for Georgia Tech CS 7638 (Robotics: AI Techniques): beginner lessons, practice questions rated from level 1 to 5, flashcards, and timed mock midterm and final exams.

- Open the GitHub Pages address in Safari, then tap Share → Add to Home Screen. After the first visit it works with no internet.
- Progress is saved on the device only.
- Hosted with GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
- `index.html` is generated from the source in the course project. Edit the source and rebuild rather than editing it by hand.
